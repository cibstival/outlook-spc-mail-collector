# Outlook 메일 자동 수집 (회계법인 SPC 업무용)

회사 PC의 Outlook에서 SPC(유동화전문회사·리츠·펀드) 자료 메일을 찾아 첨부를 **SPC별·결산월별 폴더에 자동 정리**하는 도구입니다.
작업 스케줄러로 평일 하루 두 번 창 없이 돌고, 정리된 자료는 이후 결산·감사보고서(DSD) 자동 생성 단계가 이어받습니다.

| 파일 | 하는 일 |
|---|---|
| `ingest_spc.py` | Outlook 메일 폴더 전부를 훑어 SPC 자료 메일만 골라 첨부 저장·분류(수탁사·SPC·결산월·자료 종류), zip 풀기, 중복 방지 |
| `scope.py` | 업무배정표의 담당 회사만 수집하도록 이름 맞추기(펀드·리츠 이름의 한글 숫자·오타 허용) |
| `review_mail.py` | 리뷰어(설정의 이름) 메일을 SPC별로 모아 리뷰사항 분석에 씀 |
| `fix_misrouted.py` · `dedupe_inbox.py` | 잘못 분류된 파일 바로잡기, 똑같은 사본 정리(지우지 않고 옮김) |
| `auto_run.py` · `SPC수집_자동.bat` · `자동수집_등록.ps1` | 작업 스케줄러 등록·창 없는 실행·겹침 방지 |
| `pc_agent.py` | 원격 점검용: 정해진 작업만 요청 파일로 실행 |
| `test_*.py` | 가상 SPC·가짜 사서함 시험(실제 고객 자료 없음) |

실제 설정(`spc_mail_config.json` - 도메인·회사명·경로)과 수집된 자료는 이 저장소에 없습니다. `spc_mail_config.example.json`을 복사해 채워 씁니다.
필요: Windows, Outlook, Python 3.10+, `pip install pywin32 openpyxl xlrd pyzipper`.

---

## 수집기 상세 (`ingest_spc.py`)

수탁사 메일로 온 자금판·거래내역 같은 첨부를 **SPC별·결산월별 폴더에 자동으로 넣고**, 생성 파이프라인이 읽을 대기열(`_새자료.json`)을 남긴다.

## 판별
| 무엇 | 어떻게 |
|---|---|
| 수탁사 | 보낸 사람 도메인(`domains`). 없으면 SPC 루트 폴더에서 그 SPC가 들어 있는 수탁사 |
| SPC | 첨부 파일명 → 메일 제목 순으로 SPC 이름을 찾는다. 별칭은 `spc_root/<수탁사>/<SPC>` 폴더 이름에서 '유동화전문·(유)·㈜'를 뗀 것 + `aliases` |
| 결산월 | 파일명·제목의 날짜(`2026-06-30`, `260630`, `26.06`, `_2606.`, 기간 `~`의 끝) 중 가장 늦은 것. 받은 날 이후 날짜는 만기일로 보고 뺀다. 날짜가 없으면 받은 달의 전달로 하고 로그에 표시한다. `closing_months`에 결산월이 있으면 그 결산월로 맞춘다 |
| 종류 | 운용지시서 / 세금계산서 / 잔액증명 / 발행내역 / 거래내역 / 자금판 / 기타 |

넣는 곳: `<dest_root>/<수탁사>/<SPC>/자금판 및 거래내역|운용지시서|세금계산서/<YY.MM>/`.
SPC를 판별하지 못한 첨부는 `<dest_root>/_미분류/<수신일>/`에 넣는다.

## 원칙
- 메일 본문은 저장하지 않는다. 대용량 링크를 감지할 때만 읽는다.
- 기존 파일을 덮어쓰지 않는다. 같은 메일은 두 번 처리하지 않는다(EntryID 또는 Message-ID).
- `dest_root` 기본값은 원본 SPC 폴더가 아닌 `수집함`이다. 원본으로 옮기는 일은 사람이 확인한 뒤에 한다.
- 실제 설정 `spc_mail_config.json`(도메인·SPC명)과 `수집함/`은 저장소에서 제외한다.

## 실행
```bash
copy spc_mail_config.example.json spc_mail_config.json    # 도메인·경로 채우기
python ingest_spc.py --baseline       # 처음 한 번: 기존 메일은 처리완료로만 표시
python ingest_spc.py                  # Outlook 메일 폴더 전부에서 SPC 자료 메일만 수집(outlook_folder: auto, 기본)
python ingest_spc.py --survey         # 편지함 조사: 폴더별 SPC 자료 메일 수·설정에 없는 도메인(저장 없음)
python ingest_spc.py --dry-run        # 저장 없이 분류만 확인
python ingest_spc.py --eml <폴더>     # .eml 폴더(시험·다른 메일 프로그램)
python test_ingest.py                 # 가상 SPC·가상 메일 시험(고객 자료 없음)
```

## 편지함 자동 탐색 (10-20)
- 'SPC' 편지함이나 규칙을 새로 만들 필요 없음. 기본값 `outlook_folder: "auto"`는 사서함의 메일 폴더를 하위 폴더까지 모두 본다
  (보낸·지운·임시·정크·일정·연락처 제외). 그중 첨부가 있고, 보낸이가 수탁사·은행 도메인이거나 제목·첨부 이름에 SPC 이름·자료 종류가 있는 메일만 수집.
- 같은 메일이 여러 폴더에 복사돼 있으면 인터넷 Message-ID로 한 번만 처리. `--days`면 Outlook에서 날짜로 먼저 걸러 빠름.
- 특정 폴더만: `"outlook_folder": ["수탁사", "받은 편지함/은행"]`. 빼고 싶은 폴더: `"exclude_mail_folders": ["개인"]`.
- `--survey`: 폴더별 메일 수·첨부 메일 수·SPC 자료로 보이는 메일 수·주요 보낸 도메인, 설정 domains에 없는 도메인 목록 → `수집함/_수집작업/_편지함조사.md`.
- 시험: `python test_outlook_mock.py`(가짜 사서함).

## 자동 결산까지 (수집 → B·A·D·DSD)

`SPC수집_자동.bat`이 수집 다음에 `표준화/변환기/자동결산.py`를 실행합니다.

- 대기열 `수집함/_새자료.json`에서 새로 받은 자금판·거래내역을 SPC·결산월로 묶습니다.
- 원본 SPC 폴더(읽기만)와 수집함의 그 SPC 폴더를 한 폴더처럼 읽습니다.
- 직전 결산(작성자 결산, 또는 이미 자동 생성한 결산)에서 출발해 B → A → D → DSD를 만듭니다.
- 결과는 `자동결산/<SPC>/<YY.MM>/`에 둡니다.
  - 파일: B·A·D·DSD
  - `검토요약.md`: 사람이 확인할 것, DSD 확인 칸, 직전 대비 큰 변동
  - `검토요청_메일초안.txt`: 보내지 않음
- 실행 기록은 `자동결산/_자동결산로그.md`, 처리 상태는 `_자동결산상태.json`에 남습니다. 자료가 아직 없는 결산월은 '대기'로 두고 다음 실행 때 다시 봅니다.
- 설정 `work_root`가 없으면 수집함 옆에 `자동결산` 폴더를 만듭니다.
- 하나만 돌릴 때: `python 자동결산.py --config spc_mail_config.json --spc "<SPC 폴더 이름>" --cut 2026-06-30`
